Cara Memperbaiki: dan cara update data dari komputer ke github

Jalankan (git status) untuk melihat file mana yang sudah diubah.

Jika ada file yang terdaftar di bawah "Changes to be committed," itu berarti Anda sudah melakukan (git add .), tetapi belum di-commit.

Lakukan commit dengan pesan yang jelas: (git commit -m "update file a")

Setelah itu, jalankan (git push) lagi.
